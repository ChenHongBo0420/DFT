# Example Structures

The existing repository provides 19 small structure examples:

- 10 chain structures.
- 6 crystal structures.
- 3 molecular structures.

Each sample contains a POSCAR and energy, force, and stress files. Chain and molecular samples additionally contain DOS and band-edge files. The data bytes are preserved during repository organization.

These examples were already included in this repository. No new data source, external dataset license, calculation provenance, or publication association is asserted by this cleanup. Code licensing does not establish ownership of externally sourced data. See [data formats](../docs/data.md) for file layout and task inputs.
